# 🎨 Atividade Aula 3 — Análise de Design e UX

## 📌 Sobre a atividade

Esta atividade tem como objetivo analisar dois sites diferentes a partir de princípios de **Design e UX (User Experience)**.

Foram selecionados:

- ✅ **Exemplo BOM:** um site que apresenta boas práticas de design, como harmonia visual, bom contraste, hierarquia tipográfica e uma paleta de cores adequada.
- ❌ **Exemplo RUIM:** um site que apresenta problemas de design e/ou UX, como contraste inadequado, fontes de difícil leitura, excesso de elementos ou poluição visual.

---

## 🎯 Objetivos

A atividade busca desenvolver a capacidade de:

- Identificar boas práticas de design visual;
- Analisar contraste e legibilidade;
- Observar a hierarquia das informações;
- Avaliar o uso de cores;
- Identificar problemas de UX e comunicação visual;
- Comparar diferentes soluções de design.

### 👍 Justificativa

O site foi escolhido como um **bom exemplo de design e UX** porque apresenta uma organização visual clara e agradável.

Entre os pontos positivos observados estão:

- **Harmonia visual:** os elementos estão organizados de maneira equilibrada, facilitando a compreensão da página.
- **Contraste:** existe uma boa diferença entre o fundo, os textos e os demais elementos, favorecendo a leitura.
- **Hierarquia tipográfica:** títulos, subtítulos e textos possuem diferentes níveis de destaque, permitindo identificar rapidamente as informações mais importantes.
- **Paleta de cores:** as cores utilizadas são coerentes entre si e contribuem para a identidade visual do site.
- **Legibilidade:** os textos apresentam tamanho, espaçamento e contraste adequados.
- **Organização:** a disposição dos elementos facilita a navegação e evita excesso de informações na tela.

Por esses motivos, o site pode ser considerado um exemplo de aplicação adequada de princípios de **Design Visual e UX**.

# ❌ Exemplo RUIM

## 🌐 Site escolhido

**Nome:** [NOME DO SITE]

**Link:** [COLE AQUI O LINK DO SITE]

### 📸 Print

![Print do site escolhido como exemplo ruim](./prints/site-ruim.png)

### 👎 Justificativa

O site foi escolhido como um **exemplo ruim de design e UX** porque apresenta problemas que podem dificultar a leitura, a navegação e a compreensão das informações.

Entre os principais problemas observados estão:

- **Contraste inadequado:** algumas combinações de cores dificultam a visualização dos textos.
- **Tipografia:** determinadas fontes e/ou tamanhos prejudicam a legibilidade.
- **Poluição visual:** existe uma grande quantidade de elementos competindo pela atenção do usuário.
- **Hierarquia visual pouco clara:** não é fácil identificar quais informações são mais importantes.
- **Cores:** a combinação de cores pode causar desconforto ou não apresentar uma organização visual consistente.
- **Organização:** alguns elementos poderiam ser melhor distribuídos para tornar a experiência mais intuitiva.

Esses problemas podem tornar a navegação menos agradável e dificultar o acesso do usuário às informações que procura.

# 🔎 Comparação

| Critério | ✅ Exemplo BOM | ❌ Exemplo RUIM |
|---|---|---|
| Harmonia visual | Boa organização dos elementos | Elementos visualmente desorganizados |
| Contraste | Facilita a leitura | Dificulta a leitura |
| Tipografia | Clara e legível | Pouco legível ou inadequada |
| Hierarquia | Informações bem organizadas | Hierarquia pouco evidente |
| Paleta de cores | Coerente e equilibrada | Cores pouco harmoniosas ou excessivas |
| Poluição visual | Visual limpo | Excesso de informações/elementos |
| Experiência do usuário | Navegação mais intuitiva | Navegação mais confusa |
