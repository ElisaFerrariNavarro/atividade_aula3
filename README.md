# 🎨 Atividade Aula 3 — Análise de Design e UX

## 📌 Sobre a atividade

Esta atividade tem como objetivo analisar dois sites diferentes a partir de princípios de **Design e UX (User Experience)**.

Foram selecionados:

- ✅ **Exemplo BOM:** um site que apresenta boas práticas de design, como harmonia visual, bom contraste, hierarquia tipográfica e uma paleta de cores adequada.
- ❌ **Exemplo RUIM:** um site que apresenta problemas de design e/ou UX, como contraste inadequado, fontes de difícil leitura, excesso de elementos ou poluição visual.

---

## 🎯 Objetivos

A atividade busca desenvolver a capacidade de:

- Identificar boas práticas de design visual;
- Analisar contraste e legibilidade;
- Observar a hierarquia das informações;
- Avaliar o uso de cores;
- Identificar problemas de UX e comunicação visual;
- Comparar diferentes soluções de design.
